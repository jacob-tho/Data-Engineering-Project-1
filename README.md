## Beschreibung
Erste "eigene" ETL-Pipeline mit praktischer Anwendung theoretischer Inhalte von Vorlesungen.\
Scraping von Finanzdaten mittels requests und öffentlicher API.\
Einfache Transformationsschritte mit Pandas und laden der Daten in lokaler MySQL Datenbank.

## Zukünftige Ideen
Scheduling und mehrere Quellen extrahieren, integrieren (Duplikaterkennung, Schema Matching)\
Verwendung anderer Technologien: NoSQL oder Cloud anstatt SQL verwenden, Apache Spark für Batch Processing, NiFi und Airflow \
Interaktive Dashboards / Integration in Power BI
